# MiCita Salud - Modelado de Requisitos con UML

## Descripción del Proyecto
Este repositorio contiene los artefactos de modelado funcional para la plataforma "MiCita Salud", un sistema web y móvil diseñado para gestionar la agenda de citas médicas de una IPS en la ciudad de Bucaramanga. 

El sistema permite a los pacientes consultar disponibilidad, solicitar, cancelar y reprogramar citas, además de procesar pagos y adjuntar exámenes médicos previos. Por otro lado, facilita a los médicos la gestión de su agenda diaria y el registro de la evolución clínica mediante la integración con el sistema HIS de la institución. También incluye módulos de administración para gestionar franjas horarias, reportes y roles de usuario.

## Herramienta de Modelado Utilizada
El diagrama de casos de uso de este proyecto fue diseñado utilizando **Lucidchart**, aprovechando sus capacidades de colaboración en la nube y su soporte para la notación estándar UML 2.5. 

Dado que el modelado se realizó en un entorno web, en este repositorio se encuentran versionados los archivos de exportación del diagrama en alta calidad (PNG/PDF) y la documentación de las especificaciones de los casos de uso.
